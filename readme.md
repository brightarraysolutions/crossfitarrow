# Static Site Generator for Cross Fit Arrow

Development Dependencies:
    1. NPM - On Macbook it is easiest to install NPM with home brew. Command is `brew install node`

Css & Js Dependencies:
    1. Bootstrap

Testing the Dist folder before deployment:
** Note: ** Http Server is required. Run this command `npm install -g http-server`
    1. `npm run build`
    2. `http-server dist`

To compile the static site run:
    1. `npm install`
    2. `npm start`
